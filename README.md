# CMMI Academy 2027 — public-source learning and original case assessments

Live site: <https://cmmi-trainer.vercel.app/> · Release R9 · French and English · static application, no runtime API.

## Learning content

- 40 bilingual lessons: nine foundations and 31 Practice Areas.
- 31 PA-specific applied lessons with worked examples, plus 99 public Practice Group cards and six individually published PQA practice cards.
- Original conflicting case records, interviews, practical decisions and five-question mastery checks. The repeated aggregate-rate item was replaced with 31 PA-specific transfer questions per language.
- Two 120-question forms, A and B, per language. Question stems and IDs are distinct from each other and the training banks. Multiple items within a form can share a dossier. Subject matter and reasoning patterns naturally recur across learning activities; these are educational assessments, not validated replicas of the official exam.
- 80 silent HyperFrames revision capsules, 35 seconds each, with French/English caption files. Detailed teaching continues in the lessons.
- Local progress, notes, flashcards, evidence matrix, CSV export, progress export/import, and delayed exam corrections. The 80% mastery target is a learning threshold, not the official passing score.

## Build and verify

Editable source: `data.json`, `app.js`, `app.css`. The checked-in `index.html` is generated by:

```sh
python3 build.py
python3 audit_release.py
python3 validate_release.py --git-ref HEAD
npm ci
npx playwright install chromium
npm test
```

Python 3, FFmpeg/ffprobe and Node.js 22+ are required for validation. `QA_SCREEN=desktop` or `mobile` runs one screen profile. GitHub Actions verifies them independently, in both languages. Tests use known answer keys to check scoring software; this is not evidence of human proficiency or psychometric validity.

To compare every published video and subtitle with the local manifest:

```sh
python3 validate_release.py --base-url https://cmmi-trainer.vercel.app
```

See [VIDEO_GUIDE.md](VIDEO_GUIDE.md) for rendering and safe publication, and [AUDIT_R9.md](AUDIT_R9.md) for defects, changes, verification and limitations. Normal builds use the committed source data; scripts under `scripts/` record editorial migrations and are not build steps.

## Source scope

The 2026 public Quick Reference Guide provides PA/PG summaries and six PQA practice excerpts. It does not replace the licensed full model. The 276 individual normative practice statements are not reproduced or reconstructed. Cases, numbers, examples and teaching recommendations are original.

- [CMMI Model Quick Reference Guide v4.0](https://www.isaca.org/resources/reference-guide/cmmi-model-quick-reference-guide), 25 August 2026.
- [CMMI Credentialing Guide for Practitioners](https://cmmiinstitute.com/getattachment/8051d124-5dd9-44fd-9bf0-4842c6d58b16/CMMI-Credentialing-Guide-for-Practitioners.pdf), 31 August 2026.
- [Practitioner Policy](https://cmmiinstitute.com/getattachment/dfa7876d-b91e-4fd6-84f6-b6283f099a13/POLICY-CMMI-Certification-Certified-CMMI-Practitioner-Policy.pdf), 14 July 2026.

Current public exam references describe 120 questions and four hours. They do not establish future 2027 rules. The application's translations, question difficulty, distractors and official-exam equivalence have not been independently certified.
